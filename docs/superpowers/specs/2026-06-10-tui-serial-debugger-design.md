# TUI 串口调试助手 — 设计规格

> **日期：** 2026-06-10
> **状态：** 待实现
> **方案：** A — ratatui + 事件驱动分层架构

---

## 一、项目概述

一款跨平台（macOS / Linux / Windows）的 TUI 串口调试助手，面向嵌入式开发调试场景（ARM / STM32 / ESP32 等单片机），支持多格式数据收发、快捷指令、结构化协议解析和热插拔自动重连。

---

## 二、技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| TUI 框架 | **ratatui** | Rust TUI 生态事实标准 |
| 终端后端 | **crossterm** | 跨平台、纯 Rust |
| 异步运行时 | **tokio** | 串口异步收发 |
| 串口库 | **serialport** | 跨平台串口通信 |
| 事件处理 | tokio + mpsc 通道 | 解耦串口 IO 与 UI 渲染 |
| 配置存储 | **TOML**（serde + toml） | 人类可读、配置友好 |
| 数据序列化 | **serde + serde_json** | 导出 JSON 格式 |

## 三、界面布局

```
┌──────────────────────────────────────────────────────────────┐
│  端口: /dev/ttyUSB0  波特率: 115200  8N1  流控: 无    ● 已连接 │  ← 设置栏
├───────────────────────────────────────────────┬──────────────┤
│  ── 数据收发 ──                                │ ── 快捷发送 ── │
│  ← [14:32:01.234] AT+GMR                     │ AT            │  ← 收发区 + 侧栏
│  → [14:32:01.456] OK                         │ AT+RST        │
│  ← [14:32:05.789] 48 65 6C 6C 6F             │ AT+GMR        │
│  → [14:32:05.812] 57 6F 72 6C 64             │ AT+CWMODE=1   │
│                                               │ + 添加        │
│                                               │ ✎ 编辑        │
├───────────────────────────────────────────────┴──────────────┤
│  发送 [_______________]  行尾: 无 LF CR [CRLF]  [发送]        │  ← 发送栏
├──────────────────────────────────────────────────────────────┤
│  RX:1,024  TX:512  格式:ASCII  协议:Line  Ctrl+Q 退出          │  ← 状态栏
└──────────────────────────────────────────────────────────────┘
```

### 四区布局说明

1. **串口设置栏（顶部）**：端口、波特率、数据位、校验位、停止位、流控。连接/断开按钮。端口列表支持热插拔实时更新。
2. **数据收发区（左侧主体）**：← 紫色（接收），→ 绿色（发送）。带毫秒时间戳。支持 HEX/ASCII/RAW 切换显示。可滚动，可选中文本。
3. **快捷发送侧面板（右侧）**：可滚动指令列表。底部提供增删编辑入口。点击或快捷键发送。
4. **发送栏（底部）**：文本输入框 + 行尾选择（无/LF/CR/CRLF）+ 发送按钮。
5. **状态栏（最底部）**：连接状态、RX/TX 计数、显示格式、当前协议解析器名、快捷键提示。

## 四、架构设计

### 模块树

```
src/
├── main.rs               // 入口：启动 TUI + tokio runtime
├── app.rs                // 应用全局状态、事件路由、Tick
├── event.rs              // 事件枚举：按键、串口数据、系统事件
├── ui/
│   ├── mod.rs            // UI 入口，渲染主布局
│   ├── settings.rs       // 串口设置栏组件
│   ├── terminal.rs       // 数据收发区组件
│   ├── send_input.rs     // 发送输入栏 + 行尾选择
│   ├── quick_send.rs     // 快捷发送侧面板
│   └── status.rs         // 状态栏组件
├── serial/
│   ├── mod.rs            // 串口管理：枚举、打开、关闭、发现
│   ├── reader.rs         // 异步读取任务，数据写入 App 通道
│   └── writer.rs         // 写入 + 行尾追加
├── protocol/
│   ├── mod.rs            // 协议注册与分发
│   ├── format.rs         // 显示格式：HEX / ASCII / RAW
│   └── parser.rs         // 结构化协议解析 trait + 内置解析器
├── command.rs            // 快捷指令 CRUD + 持久化（JSON 文件）
├── export.rs             // 数据导出：CSV / JSON / 纯文本
└── config.rs             // 配置持久化（TOML 格式）
```

### 依赖层次

```
UI 层 (ratatui)
       ↓ 事件 / 状态读取
App 层 (状态管理 + 事件路由)
       ↓ 方法调用
┌──────┬──────┬──────┬──────┬──────┐
│ 串口  │ 协议  │ 指令  │ 导出  │ 配置  │
└──────┴──────┴──────┴──────┴──────┘
```

### 设计原则

- **UI 与逻辑分离**：UI 组件仅负责渲染，不持有串口引用，不执行 IO
- **App 是唯一状态持有者**：所有数据通过事件驱动更新
- **协议解析通过 trait 抽象**：内置解析器，支持扩展
- **串口 IO 为独立 tokio task**：通过 mpsc 无界通道与 App 通信

## 五、数据流与事件处理

### 事件枚举

```rust
pub enum Event {
    Key(KeyEvent),                  // 按键事件
    RxData(Vec<u8>),                // 串口收到数据
    PortsChanged,                   // 端口列表变化（热插拔）
    SerialError(String),            // 串口错误/断开
    Tick,                           // 定时 tick（UI 刷新、自动重连）
    Quit,                           // 退出
}
```

### 主循环

```
事件源（按键/串口/Tick） → App.handle_event()（状态更新） → UI 渲染（ratatui::Frame）
```

### 串口数据通道

- **接收路径**：串口设备 → SerialReader task → mpsc::Sender → App → 解码 → 写入缓存 → UI 渲染
- **发送路径**：用户按键 → App → 追加行尾 → SerialWriter → 串口设备
- **通道类型**：mpsc::unbounded（两端无阻塞）
- **共享状态**：Arc<Mutex<T>> — 数据缓存、指令列表

## 六、协议解析模块

### 显示格式

```rust
pub enum DisplayFormat {
    Hex,     // "48 65 6C 6C 6F"
    Ascii,   // 可打印字符原样，不可打印用 . 替代
    Raw,     // 原始字节
}
```

用户通过 `Ctrl+D` 切换格式，仅影响显示，不修改原始缓存数据。

### 结构化协议解析

```rust
pub trait ProtocolParser {
    /// 解析器名称，用于 UI 显示
    fn name(&self) -> &str;

    /// 尝试解析数据，成功返回结构化字符串，失败返回 None 回退到原始格式
    fn try_parse(&self, data: &[u8]) -> Option<String>;
}
```

内置解析器：
- **LineProtocol**：按行分割显示
- **ModbusRTU**：解析 Modbus RTU 帧
- **JSONProtocol**：检测 JSON 并美化显示

解析器按优先级链式尝试，失败不丢数据。通过 `Ctrl+P` 切换。

## 七、热插拔与自动重连

- 每 2 秒调用 `serialport::available_ports()` 扫描端口列表
- 变化时触发 `PortsChanged` 事件，UI 下拉列表实时更新
- 被动断开（设备拔出/异常）自动进入重连模式
- 主动断开（用户手动操作）不触发自动重连
- 自动重连达到 10 次失败后停止，转为等待用户手动操作
- 重连使用上次相同的串口参数

## 八、数据导出

- **格式**：CSV / JSON / 纯文本
- **范围**：全部 / 最近 N 行 / 按时间筛选
- **触发**：`Ctrl+E` 弹出保存对话框
- **CSV 列**：时间戳,方向,数据内容
- **JSON 结构**：`[{time, dir, data}]`

---

## 九、配置持久化

- **存储格式**：TOML
- **文件路径**：`~/.config/serial/config.toml`
- **内容**：
  - 串口参数（端口、波特率、数据位、校验位、停止位）
  - 行尾偏好、显示格式
- **快捷指令**：单独存储到 `~/.config/serial/commands.json`
- **行为**：启动时自动加载，退出时自动保存

## 十、快捷键规划

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Q` | 退出程序 |
| `Ctrl+C` | 连接 / 断开串口 |
| `Ctrl+D` | 切换显示格式（HEX ↔ ASCII ↔ RAW） |
| `Ctrl+E` | 导出数据 |
| `Ctrl+L` | 清空收发区 |
| `Ctrl+P` | 切换协议解析器 |
| `Ctrl+R` | 重新扫描端口 |
| `Tab` | 切换焦点区域 |
| `↑ ↓` | 列表导航 / 浏览快捷指令 |
| `Enter` | 发送 / 确认选择 |
